# Latex

1. Install `mactex-no-gui` (full TeXLive) using `brew`
1. Install the `TeXiFy-IDEA` JetBrains plugin to use with your JetBrains IDE
1. Use the TexLive package manager to run 

```shell
tlmgr update --self
tlmgr  install collection-latex
```

Now you can open your LaTeX projects and set up the document compilation (compiler, main file, output location)
